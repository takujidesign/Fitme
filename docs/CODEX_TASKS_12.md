## A. Security findings from Claude's review (fix all)
1. **No password reset.** Add "ลืมรหัสผ่าน": `POST /api/auth/forgot` (always returns 200, same message whether the email exists) → email via Resend with a single-use token (32 bytes, store SHA-256 only, 30 min TTL) → `#/reset/<token>` → `POST /api/auth/reset` sets a new password and **revokes all sessions** of that user. Rate-limit per IP and per email.
2. **No email verification.** On register send a verification link (single-use token, 24 h). Until verified: the account works for private features, but cannot send friend requests, chat, post ideas, check in publicly, or upload an avatar. "ส่งอีกครั้ง" (max 3/hour). If Resend is not configured, verification is skipped (admin setup checklist shows a warning).
3. **Mass registration.** Rate limit is per IP+email, so one IP can create unlimited accounts with different emails. Add a per-IP cap (5 registrations/day, 20 logins/15 min across emails) **and** Cloudflare Turnstile on register, forgot-password and idea/report submission: widget `https://challenges.cloudflare.com/turnstile/v0/api.js` (add to CSP), server verify `POST https://challenges.cloudflare.com/turnstile/v0/siteverify` with `secret`, `response`, `remoteip`. Site key + secret entered in the admin page (secret encrypted like other keys); when not configured, Turnstile is skipped and the setup checklist shows a warning.
4. **Sessions.** Add "เปลี่ยนรหัสผ่าน" (requires current password; revokes other sessions), "ออกจากระบบทุกอุปกรณ์", and a list of active sessions (created, last used, user agent family). Admin "suspend" also revokes the user's sessions and blocks AI/credit endpoints, not only social ones.
5. **Admin 2FA without Wrangler.** `ADMIN_TOTP_SECRET` currently must be a Wrangler secret, which the owner cannot easily set. Add enrolment in the admin System section: generate secret in the browser → show QR (otpauth URI) + manual key → confirm with a 6-digit code → store encrypted in CONFIG KV (same AES-GCM scheme as other secrets); env secret still overrides. Provide 8 one-time recovery codes (hashed). Disabling 2FA requires a current code.
6. **No security headers on the website.** Add `app/_headers` (copied to `web/dist` by `web/deploy.mjs`; Workers static assets honour `_headers`) with: `Content-Security-Policy` (default-src 'self'; script-src 'self' https://challenges.cloudflare.com; connect-src 'self' https://api.fixmee.app https://generativelanguage.googleapis.com https://challenges.cloudflare.com plus the configured map tile host via a documented placeholder; img-src 'self' data: blob: https://cdn.jsdelivr.net <tile host>; frame-src https://challenges.cloudflare.com; object-src 'none'; base-uri 'self'; frame-ancestors 'none'), `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` (camera=(self), geolocation=(self), microphone=(), payment=()), `Strict-Transport-Security: max-age=31536000; includeSubDomains`. Remove any inline scripts/handlers that the CSP would block. API responses: add `X-Content-Type-Options` and `Strict-Transport-Security`.
7. **Account enumeration.** Register with an existing email: when verification is on, respond like a normal sign-up ("ตรวจอีเมลของคุณ") and email the existing owner instead of returning 409.
8. **VAPID subject.** `VAPID_SUBJECT` in `wrangler.toml` is a placeholder. Use `mailto:<contact email from admin settings>` at runtime when set; keep the var only as a fallback. Do not commit any personal email.
