# เช็กลิสต์แจ้งเตือน Round 21 — ประมาณ 30 นาที

ใช้บัญชีทดสอบ ข้อมูลยาสมมติ และอุปกรณ์สองเครื่องที่เข้าสู่บัญชีเดียวกัน ตั้งเตือนล่วงหน้า 5 นาที จดรุ่นเครื่อง ระบบ เบราว์เซอร์ เวลา และผลจริง ใช้รายการหลักกับแต่ละแพลตฟอร์ม; การครบทุกแพลตฟอร์มอาจต้องแยกรอบ 30 นาที

## นาที 0–5: เปิดใช้งาน

- [ ] iPhone ในแท็บ Safari: เปิดการตั้งค่าแจ้งเตือน → ต้องแสดงให้เพิ่มไปยังหน้าจอโฮมก่อน
- [ ] iPhone PWA จากหน้าจอโฮม: เปิดสิทธิ์ → ส่งทดสอบถึงตัวเอง → เห็นแจ้งเตือน
- [ ] Android Chrome ทั้งติดตั้งและในเบราว์เซอร์: เปิดสิทธิ์และส่งทดสอบ → เห็นแจ้งเตือน ไม่ต้องบังคับติดตั้ง
- [ ] Desktop Chrome, Firefox และ Safari: ทำขั้นตอนเปิดสิทธิ์และ self-test → เห็นแจ้งเตือน หรือระบุข้อจำกัดแพลตฟอร์มอย่างชัดเจน

## นาที 5–12: ปิดแอปและความเป็นส่วนตัว

- [ ] ตั้งยาและมื้ออาหารในอีก 5 นาที แล้วปิดแอป/ล็อกหน้าจอ → แจ้งเตือนมาถึงตามรอบ cron (อาจคลาดเคลื่อนได้ประมาณ 5 นาที)
- [ ] ค่าเริ่มต้น “เฉพาะยา” → ไม่เห็นชื่อยาและขนาดยาบนหน้าจอล็อก ชื่อเป็น “Fixmee: ถึงเวลาแล้ว” และไม่มีเนื้อหา
- [ ] เลือก “ทุกการแจ้งเตือน” → ชื่อเตือนมื้ออาหารก็เป็นข้อความทั่วไป
- [ ] เลือก “ปิด” → เตือนครั้งถัดไปแสดงรายละเอียดตามแผน
- [ ] เปิดจากแจ้งเตือนยา → รายละเอียดอ่านได้ภายในแอป; แตะแชท → เปิดบทสนทนาที่ถูกต้อง
- [ ] Done → รายการไม่อยู่ในรายการที่พลาด; Snooze → เลื่อนไป 10 นาที (ถ้าปิด PWA ออฟไลน์ การเตือนเว็บแบบเลื่อนต้องรอเปิดแอป; native ใช้ scheduler ของเครื่อง)
- [ ] Badge → นับรายการวันนี้ที่ถึงเวลาแต่ยังไม่ทำ; Done/Snooze แล้วลด และเป็นศูนย์แล้วหาย ปิดสวิตช์ badge แล้วไม่แสดง
- [ ] Android ถ้ามาช้า: จดสถานะ Battery optimisation / Background restriction แล้วทดสอบอีกครั้งหลังอนุญาตเบื้องหลัง การประหยัดแบตอาจชะลอการส่ง

## นาที 12–20: เวลาเงียบและสองเครื่อง

- [ ] ตั้งเวลาเงียบให้สิ้นสุดในอีก 2 นาที ส่งแชท 3 ข้อความจากอีกบัญชี → ช่วงเงียบไม่มี push; หลังสิ้นสุดและถึง cron รอบถัดไป ได้หนึ่งแจ้งเตือนรวมต่อบทสนทนา ไม่มีข้อความแชทจริง
- [ ] ปิดข้อความแชท / กิจกรรมเพื่อน → ไม่ได้รับหมวดที่ปิด
- [ ] ตั้งเตือนเดียวกันในเครื่อง A และ B แล้ว Done ที่ A ขณะ B ยังมีรายการรอส่ง → B ไม่ส่งสำเนานั้นหลัง ack ถึงเซิร์ฟเวอร์; เปิด B แล้วรายการที่พลาดซ่อนรายการนั้น
- [ ] เปลี่ยนภาษาที่ B → ID ของการเตือนเดียวกันยังตรงกัน
- [ ] เครื่องที่ไม่เข้าสู่บัญชี → Done มีผลเฉพาะเครื่องนั้น
- [ ] หมายเหตุ: ไม่ส่ง silent dismiss push; แจ้งเตือนที่แสดงไปแล้วบน B จะปิดเมื่อเปิด B และดึง ack ในแพลตฟอร์มที่รองรับ KV มี propagation delay จึงจดเวลาทั้งสองเครื่องด้วย

## นาที 20–30: ออฟไลน์ ปฏิทิน และการต่ออายุ

- [ ] นำเข้าปฏิทิน/สมัครลิงก์ให้เรียบร้อย จากนั้นเปิดโหมดเครื่องบิน → alarm ปฏิทินยังดัง; เปิดแอปครั้งถัดไปเห็นรายการที่พลาด
- [ ] เปลี่ยนเขตเวลาเครื่อง แล้วเปิดแอปออนไลน์ → ตารางที่ลงทะเบียนใช้เขตเวลาใหม่
- [ ] ปฏิเสธสิทธิ์แจ้งเตือนจากการตั้งค่าเบราว์เซอร์ แล้วเปิดแอป → push ปิดและมีคำอธิบายสิทธิ์ถูกปฏิเสธ
- [ ] เปิดแอปหลัง 24 ชั่วโมง → ต่ออายุการลงทะเบียน; เปิดซ้ำในวันเดียวกันโดยไม่เปลี่ยนแผน/ตั้งค่า → ไม่ลงทะเบียนซ้ำ
- [ ] ยกเลิกลิงก์ปฏิทิน → subscribed events หายหลังแอปปฏิทินรีเฟรช (ผู้ให้บริการอาจใช้เวลาหลายชั่วโมง); ไฟล์ .ics ที่นำเข้าเองต้องลบปฏิทินเอง
- [ ] Logout → ไม่ได้รับ push ใหม่จาก subscription ที่ถอดแล้ว
