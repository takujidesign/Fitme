# เช็กลิสต์ก่อนเปิดใช้ Fixmee (สิ่งที่เจ้าของต้องทำเอง)

ทำตามลำดับได้เลย ข้อที่มี ⏳ ให้ทำหลังรอบ 12 ขึ้นเว็บแล้ว ห้ามส่งคีย์/รหัสใดๆ ให้ Claude หรือ Codex — ใส่ในหน้าแอดมินหรือ Cloudflare เองเท่านั้น

---

## ส่วนที่ 1 — ความปลอดภัยของแอดมิน (ทำก่อน)

### 1.1 เปลี่ยนรหัสแอดมินให้ยาวและสุ่ม
1. เปิด https://dash.cloudflare.com → บัญชี togsdesign
2. เมนูซ้าย **Workers & Pages** → **fitme-api** → แท็บ **Settings** → **Variables and Secrets**
3. แถว `ADMIN_PASSWORD` → **Edit** → ใส่รหัสใหม่อย่างน้อย 20 ตัว (ใช้ password manager สุ่มให้) → **Deploy**
4. บันทึกรหัสไว้ใน password manager

### 1.2 ⏳ เปิดล็อกอิน 2 ชั้น (2FA)
1. ติดตั้งแอป Google Authenticator / Microsoft Authenticator / 1Password ในมือถือ
2. เปิด https://fixmee.app/#/admin → ล็อกอิน → **ระบบ** → **ความปลอดภัยแอดมิน** → **เปิด 2FA**
3. สแกน QR ด้วยแอปในมือถือ → พิมพ์รหัส 6 หลักเพื่อยืนยัน
4. **เก็บ recovery codes 8 ชุด** ไว้ในที่ปลอดภัย (ใช้ตอนทำมือถือหาย)

## ส่วนที่ 2 — ตั้งค่าในหน้าแอดมิน → "ตั้งค่าเริ่มต้น"

เปิด https://fixmee.app/#/admin → **ตั้งค่าเริ่มต้น** แต่ละการ์ดมีปุ่ม **ทดสอบ** กดทุกข้อจนขึ้น ✓

### 2.1 PromptPay และอีเมลติดต่อ (สำคัญที่สุด)
- **PromptPay ID**: เบอร์มือถือหรือเลขบัตรประชาชน/เลขผู้เสียภาษีที่ผูก PromptPay (ตอนนี้ยังเป็น 0812345678 — ถ้าไม่เปลี่ยน เงินบริจาคจะไปผิดคน)
- **ชื่อผู้รับเงิน**: พิมพ์ให้ตรงกับชื่อที่ขึ้นในสลิปเวลามีคนโอนให้คุณ (ระบบใช้ตรวจสลิป)
- **อีเมลติดต่อ**: อีเมลที่อยากให้ผู้ใช้ติดต่อ (ใช้ในหน้านโยบาย และเป็น contact ของระบบแจ้งเตือน)
- ทดสอบ: สแกน QR ตัวอย่างในหน้าแอดมินด้วยแอปธนาคาร ต้องขึ้นชื่อคุณ (ไม่ต้องโอนจริงก็ได้)

### 2.2 ระบบแจ้งเตือน (VAPID)
1. การ์ด **การแจ้งเตือน** → **สร้างคีย์** → **บันทึก**
2. กด **ส่งแจ้งเตือนทดสอบมาที่เครื่องนี้** → อนุญาตการแจ้งเตือน → ต้องเด้งขึ้น

### 2.3 อีเมล (Resend) — ใช้ยืนยันอีเมลและรีเซ็ตรหัสผ่าน
1. สมัคร https://resend.com (ฟรี 3,000 อีเมล/เดือน)
2. **Domains** → **Add domain** → `fixmee.app` → Resend จะให้ DNS records 3–4 อัน (TXT/MX/CNAME)
3. ไปที่ Cloudflare → **fixmee.app** → **DNS** → **Add record** ใส่ตามที่ Resend ให้ทีละอัน (Proxy status = **DNS only**)
4. กลับ Resend กด **Verify** (อาจรอ 5–30 นาที)
5. **API Keys** → **Create API key** (permission: Sending access, domain: fixmee.app) → คัดลอก
6. หน้าแอดมิน → การ์ด **อีเมล** → วางคีย์ → **ทดสอบ** (ส่งไปอีเมลติดต่อ)

### 2.4 ⏳ กันบอท (Cloudflare Turnstile — ฟรี)
1. Cloudflare dashboard → เมนูซ้าย **Turnstile** → **Add widget**
2. Widget name: `Fixmee` · Hostnames: `fixmee.app` และ `www.fixmee.app` · Widget mode: **Managed**
3. **Create** → จะได้ **Site Key** และ **Secret Key**
4. หน้าแอดมิน → การ์ด **Turnstile** → วางทั้งสองคีย์ → **ทดสอบ**

### 2.5 ตรวจสลิป (Thunder) — ถ้าอยากให้ป้ายผู้สนับสนุนอัตโนมัติ
1. ล็อกอิน Thunder → เมนู API / Developer → สร้าง API key
2. หน้าแอดมิน → การ์ด **Thunder** → วางคีย์ → **ทดสอบ**
3. ทดสอบจริง: หน้า **สนับสนุน** → โอน 1 บาทเข้าบัญชีตัวเอง → แนบสลิป → ต้องได้ป้ายผู้สนับสนุน

### 2.6 รับบริจาคต่างประเทศ (ไม่บังคับ)
- **Wise**: ต้องเป็นบัญชี **Wise Business** → สร้าง payment link / QuickPay → วางลิงก์ในการ์ด **บริจาค**
  - เช็กก่อนว่าบัญชีที่อยู่ไทยของคุณเปิด Wise Business ได้ไหม ถ้าไม่ได้ ใช้ Stripe Payment Link แทน
- **Stripe** (ทางเลือก): Stripe dashboard → **Payment Links** → สร้างลิงก์แบบ "Customers choose what to pay" → วางลิงก์

### 2.7 แผนที่ยิม (ไม่บังคับ — ไม่ใส่ก็ใช้แบบรายการได้)
1. สมัคร https://www.maptiler.com (มี free tier)
2. **API keys** → สร้างคีย์ → ตั้ง **Allowed HTTP origins** = `https://fixmee.app` (สำคัญ กันคนอื่นเอาไปใช้)
3. หน้าแอดมิน → การ์ด **แผนที่** → ใส่ URL `https://api.maptiler.com/maps/streets-v2/{z}/{x}/{y}.png?key=คีย์ของคุณ`

### 2.8 AI แบบเครดิต (Claude) — ไม่บังคับ
1. https://console.anthropic.com → **API Keys** → **Create Key**
2. **Settings → Limits** → ตั้ง **monthly spend limit** (เช่น $20) กันบิลบานปลาย
3. หน้าแอดมิน → การ์ด **Claude** → วางคีย์ → **ทดสอบ**
4. ถ้ายังไม่อยากเปิด: แอดมิน → **AI** → ปิด engine Claude

### 2.9 ภาษา
- เปิดไว้แค่ **ไทย + อังกฤษ** ก่อน (ค่าเริ่มต้นหลังรอบ 12) จนกว่าจะมีเจ้าของภาษาตรวจ จีน/ญี่ปุ่น/เวียดนาม

## ส่วนที่ 4 — ระบบดูแลหลังเปิดใช้

### 4.1 แจ้งเตือนเมื่อเว็บล่ม (ฟรี)
1. สมัคร https://uptimerobot.com
2. **Add New Monitor** → HTTP(s) → URL `https://api.fixmee.app/api/health` → ทุก 5 นาที → แจ้งเตือนทางอีเมล
3. เพิ่มอีกอัน URL `https://fixmee.app/`

### 4.2 ซ้อมกู้ข้อมูล (ทำเดือนละครั้ง)
- แอดมิน → **ระบบ** → **สำรองข้อมูล** → ดาวน์โหลดไฟล์ล่าสุด → เปิดดูว่าไฟล์ไม่เสีย (เป็น .json.gz)

### 4.3 ดูแลชุมชน
- เปิดหน้าแอดมิน → **ชุมชน/ความปลอดภัย** อย่างน้อยวันละครั้ง จัดการรายงาน
- ถ้ายังไม่พร้อมดูแล: **ระบบ → Feature flags** → ปิด chat / check-in ไว้ก่อน

## ส่วนที่ 5 — เรื่องกฎหมายและเนื้อหา (ต้องใช้ผู้เชี่ยวชาญ)
1. ส่ง `docs/PDPA_RECORD.md` + หน้า privacy/terms ให้นักกฎหมาย (PDPA) ตรวจ แล้วเอาฉบับจริงมาให้ Claude ใส่แทนฉบับร่าง
2. ให้นักโภชนาการ/เทรนเนอร์ลองใช้แผนอาหาร อาหารเสริม และคำเตือนโรคประจำตัว แล้วจดสิ่งที่ต้องแก้
3. ถ้าจะเปิด จีน/ญี่ปุ่น/เวียดนาม: ให้เจ้าของภาษาตรวจไฟล์ `app/js/i18n/zh.js`, `ja.js`, `vi.js` ก่อน

## ส่วนที่ 6 — ปิดของเก่า (ทำหลังเปิดใช้ 2–4 สัปดาห์)
1. GitHub → repo **Fitme** → **Settings** → **Pages** → **Unpublish site** (เว็บเก่า takujidesign.github.io/Fitme จะหายไป)
2. **Settings** → **General** → เลื่อนล่างสุด **Danger Zone** → **Change visibility** → **Private**
   - GitHub Actions ยัง deploy อัตโนมัติได้ (ฟรี 2,000 นาที/เดือน สำหรับ repo private)
3. บอก Claude ให้ปิด URL `workers.dev` ของ API (แก้ `workers_dev = false`)

## ส่วนที่ 7 — เปิด beta
1. ชวนเพื่อน 5–10 คน ใช้ 1–2 สัปดาห์
2. ให้เสนอปัญหา/ไอเดียผ่าน **บอร์ดเสนอฟีเจอร์** ในแอป
3. ดูแดชบอร์ดแอดมินทุกวัน: error, รายงาน, ต้นทุน AI

## Round 19 — SEO หลังเจ้าของอนุมัติเผยแพร่
- ยืนยันโดเมน fixmee.app ใน Google Search Console และ Bing Webmaster Tools ด้วย DNS TXT ผ่าน Cloudflare
- ส่ง https://fixmee.app/sitemap.xml ให้ทั้งสองบริการ
- ตรวจหน้าแรกและท่าออกกำลังกาย ตรวจ canonical และสถานะ 404 ของเส้นทางที่ไม่มีจริง
- ตรวจ coverage และรายงานการจัดทำดัชนีหลัง 1–2 สัปดาห์ แก้รายการยกเว้นที่ไม่ตั้งใจ
- เลือกใช้ IndexNow ได้ โดยเจ้าของเป็นผู้ตั้งค่าและส่ง URL
